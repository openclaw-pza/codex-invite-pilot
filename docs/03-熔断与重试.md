# 03 · 熔断与重试

> 怎么发现它卡住了——而不是等它烧完时间。

## 1. 一句话

无人值守的流程有两种死法：**报错死**和**转圈死**。

报错死是好事——它自己停下来了，日志里有原因。
转圈死才是麻烦：程序活着、日志在刷、每一步都"成功"，
但它一直在原地重复同一件事，直到把总时间耗完。

熔断就是专门抓第二种的。

## 2. 为什么不能用显而易见的做法

显而易见的做法是：**数失败次数**。连续失败 N 次就停。

它抓不到转圈死，原因很直接：**转圈的时候没有失败。**

每一轮都能找到那个按钮、每一轮都点得动、每一轮都返回成功。
失败计数器一次都不增长，于是熔断永远不触发。

这不是把阈值调小能解决的——计数的**对象**就选错了。

## 3. 踩过的坑

### 3.1 空转 135 轮，监控全程显示"正常"

真实事故：一轮跑到 OAuth 阶段，卡在某一屏上**连续循环 135 次、烧掉 7 分钟**，
直到总预算耗尽才退出。

当时的熔断计数器叫 `stuck`，只在**点不到元素**时增长。而实际情况是：

- 元素每次都找得到
- 每次点击都成功
- 页面纹丝不动

于是 `stuck` 一直是 0，熔断从来没有触发过。日志里刷的全是"命中"。

**改法是换一个观察对象：不看动作，看页面。**

```
页面指纹 = 当前地址 + 正文开头一段
连续 15 轮指纹完全不变 → 判定原地打转，立刻熔断
```

这一条上线之后，当轮就抓出了下一个缺陷——因为它第一次让"卡住"变成了
一个**会报错的事件**，而不是一段安静流逝的时间。

> 这就是 [02 判据层](02-判据层.md) 那条规矩在熔断上的样子：
> **判据落在产物上，不落在动作上。** 熔断也是一种判据。

### 3.2 熔断必须留下现场

熔断触发时如果只抛一个"卡住了"，排查等于从零开始——
你不知道它卡在哪一屏、页面上当时写着什么。

所以熔断这一步同时做三件事：**截图、把当前地址和正文开头写进错误消息、然后才抛错**。

错误消息长这样：

```
OAuth 原地打转：连续 15 轮页面无变化，停在 <地址>｜<正文开头 160 字>
```

有了这行，绝大多数"卡住"当场就能定位到是对方加了一屏没见过的界面。

### 3.3 重试预算要花在对的失败形态上

手机验证那里原本有 3 次换号预算。但它只在**"退回重填手机号"这一种失败**上生效，
而实际最常见的失败形态是**停在验证码输入页不动**——那种情况一次预算都用不上。

结果就是：预算写了，但对真实故障零作用。

改法是让最常见的那种失败也能消费预算：还有次数就主动退回上一屏、换个号重来。

> 一般规矩：**加重试之前，先确认你的重试路径覆盖的是真实发生的那种失败。**
> 按想象中的失败模式设计的重试，跑一年也不会被触发一次。

### 3.4 退避不是可选项

队列消费者连不上服务端时，如果不做退避，它会每 5 秒重试一次——
日志被刷屏，而真正的原因一条都看不出来。

所以正常轮询和故障退避是两个不同的间隔：**空闲时几秒一轮，出故障时几十秒一轮**。
后者的作用不只是省资源，主要是**让日志还能看**。

## 4. 代码在哪

| 机制 | 位置 |
|---|---|
| 页面指纹熔断 | `scripts/desktop/desktop-run.mjs`，阶段 4 的 `lastSig` / `sameSig` |
| 总预算掐表 | 同文件，`WINDOW_BUDGET_MS` + `W0` |
| 换号重试预算 | 同文件，`phoneTries` |
| 队列退避 | `scripts/invite-worker.mjs`，`IDLE_MS` / `BACKOFF_MS` |
| 陈旧任务回收 | `server/accountPool.js`，`reclaimStaleRunning` → [04 号池](04-号池.md) |

关键片段：

```js
// 页面指纹：地址 + 正文开头。连续不变 = 在原地打转。
const sig = `${page.url()}|${t.slice(0, 300)}`;
if (sig === lastSig) sameSig += 1; else { sameSig = 0; lastSig = sig; }
if (sameSig >= 15) {
  await page.screenshot({ path: SHOTS + '/dk-X-noprogress.png', fullPage: true }).catch(() => {});
  throw new Error(`OAuth 原地打转：连续 ${sameSig} 轮页面无变化，停在 ${page.url()}｜${t.slice(0, 160)}`);
}
```

注意截图那句后面跟着 `.catch(() => {})`：**留证据失败不该盖掉真正的错误**。
截不出图是次要问题，把它抛出去会让你看到"截图失败"而看不到"原地打转"。
